# Bruchrechnen üben

Interaktive Übungsseiten zur Bruchrechnung für Klasse 6, im Bleistift-Stil auf Karopapier.

| Seite | Inhalt |
| --- | --- |
| [erweitern-kuerzen.html](erweitern-kuerzen.html) | Erweitern und Kürzen (verfeinern/vergröbern), Streifentafel |
| [addieren.html](addieren.html) | Brüche addieren Schritt für Schritt |
| [subtrahieren.html](subtrahieren.html) | Brüche subtrahieren Schritt für Schritt |
| [multiplizieren.html](multiplizieren.html) | Bruch mal Zahl, dann Bruch mal Bruch |
| [dividieren.html](dividieren.html) | Bruch durch Zahl, dann Bruch durch Bruch, Kehrwert |

Startseite: `index.html`

## Veröffentlichen mit GitHub Pages

1. Alle Dateien dieses Ordners in ein GitHub-Repository hochladen.
2. Im Repository: Settings → Pages → Branch `main`, Ordner `/ (root)` → Save.
3. Nach kurzer Zeit ist die Seite unter `https://<benutzername>.github.io/<repository>/` erreichbar.

Die Seiten brauchen keinen Server und keine Installation. Die Handschrift-Schrift wird von Google Fonts geladen.
